# 📊 GitHub Profile & Repo Visual Analytics

An interactive web dashboard built with JavaScript, Tailwind CSS, and Chart.js to inspect any GitHub user's profile, generate visual language analytics, calculate a Developer Score, and display top repositories in real-time.

---

## ✨ Features

- **Profile Overview:** Quick overview of followers, public repositories, bio, and avatar.
- **Developer Score Algorithm:** Custom score calculated based on repos, stars, and total followers.
- **Language Distribution Chart:** Interactive Doughnut chart built with Chart.js showing language breakdown.
- **Top Repositories:** Displays top 5 repositories ordered by star count with forks and repo links.
- **Zero Backend Required:** Directly fetches live data using GitHub REST API.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, JavaScript (ES6+ async/await)
- **Styling:** Tailwind CSS (CDN)
- **Data Visualization:** Chart.js
- **API:** GitHub Public REST API
